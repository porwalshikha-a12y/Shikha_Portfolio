- Test Dataset in excel format was taken from opensource
- Ingested into powerbi desktop and a model was created using date dimensions, User     dimension and tradeflow dimension.
- UserFlow Analysis dashboard was created.
- Trade / Asset management Reconciliation dashboard was created.
