This Power BI data analysis project demonstrates my ability to build analytical dashboards and data models that enable finance teams to explore data, monitor key metrics, and generate actionable insights.

### Project Overview

* Test dataset in Excel format was sourced from an open-source dataset.
* Data was ingested into Power BI Desktop.
* A dimensional data model was created using Date, User, and Trade Flow dimensions.
* A User Flow Analysis dashboard was developed to analyse user activity over time.
* A Trade / Asset Management Reconciliation dashboard was developed to support reconciliation and analysis.
